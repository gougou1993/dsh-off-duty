# 下班铃（Off-duty bell）

一个有趣的定时下班提醒插件。打开左侧「下班铃」入口，配置好时间和文案，到点就会弹出提醒，附带从左到右的滑入动画、文案轮播、提示音与打卡日历。纯 Client 插件，配置与打卡记录保存在浏览器 localStorage。

## 插件信息

| 字段 | 值 |
| --- | --- |
| 包名 | `@oakzhong/dsh-off-duty` |
| 版本 | `1.0.1` |
| 入口 | `index.js`（Host，空实现）· `client.js`（Client） |
| 类型 | DSH bundle 插件，ES 模块（`"type": "module"`、`"private": false`、MIT） |
| 侧边栏入口 | 下班铃（左侧） |

## 功能

### 1. 时间与触发
- 设置下班时间（HH:mm），到点自动提醒。
- 可勾选「仅工作日提醒」（周一至周五，周末静默）。
- 可一键启用/禁用提醒。
- 同一天只触发一次；打卡后当天不再提醒。
- 「再干一会」按钮延后 15 分钟再提醒。

### 2. 自定义文案与轮播
- 多行文本框任意编辑提醒文案（每行一条）。
- 到点后按顺序轮播，间隔秒数可调（1–60 秒）。
- 内置 5 条默认文案（含 "Are you ready? Go go go! 下班？" / "Are you ok?" / "今天也辛苦了，给你加个大鸡腿 🍗" 等）。

### 3. 动画与提醒方式
- 动画效果：从左到右滑入（slide）/ 淡入淡出（fade）/ 打字机（typewriter）。
- 提醒方式：右上角横幅（banner）/ 全屏遮罩（overlay）。
- 提示音：6 种 Web Audio 合成音效可选（和弦 / 钟声 / 叮咚 / 马林巴 / 电子音 / 关闭），无需外部音频文件，可点「试听」预览。
- 打卡时撒花粒子动画。

### 4. 打卡与数据
- 「打卡下班」记录当天打卡，撒花庆祝。
- 打卡日历（当月视图，已打卡日期高亮，今天描边）。
- 统计：连续打卡天数、本月打卡数、累计打卡数。

### 5. 预览与测试
- 面板提供「测试提醒」/「预览效果」按钮，立即查看动画，无需等到点。
- 设置修改后点「保存设置」持久化。

## Host API

无（Host 半片为空实现），全部逻辑在 Client 端。

## 安装与使用

1. 将本 bundle 安装到目标 DSH profile 并刷新 Harness Web UI。
2. 左侧打开「下班铃」。
3. 设置下班时间、编辑文案、选动画与提醒方式，点「保存设置」。
4. 到点会自动弹出提醒；也可点「测试提醒」立即预览。
5. 每天点「打卡下班」积累连续记录。
